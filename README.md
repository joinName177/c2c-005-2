# c2c-005 · 声音表情包工坊

Vue 3 + TypeScript + Vite 纯前端声音创作工具。支持最长 10 秒录音/导入、裁剪、人声与背景声混音（起播位置、循环、独立音量、人声闪避、循环接缝交叉淡化、削波整体降低）、声学特征情绪匹配、Canvas 封面、IndexedDB 本地作品集和系统文件分享。

## 架构

- `src/core`：作品模型、混音引擎、特征归一化、情绪规则与封面预设
- `src/ports`：录音、音频分析、裁剪与混音、Canvas、仓储与分享接口
- `src/adapters`：MediaRecorder、Web Audio（含混音渲染）、Canvas、IndexedDB、Web Share 实现
- `src/ui`：Vue 阶段式工作流和原生 CSS

## 混音工作台要点

- 成品长度以人声选段为准且不超过 10 秒；背景与真人声采样率/声道不同会重采样、上下混到同一时间轴。
- 循环背景在接缝处做交叉淡化；人声出现时背景快速压低、停顿后按设定时长逐渐恢复。
- 两路叠加超过可表达音量时先提示削波风险，用户选择“整体降低”后两路同比例衰减导出，不分别截断改变比例。
- 试听、情绪分析与保存只使用确认后的混音；原始人声选段保留可撤回。更换背景或修改参数会立即使旧混音失效；背景解码失败时保留上次有效配置与结果。

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

本地开发默认由 Vite 提供；Docker 部署访问 `http://localhost:8105`。浏览器录音在非 localhost 环境通常需要 HTTPS 和麦克风权限。

声音只保存在本机 IndexedDB，不会上传。生成的分享链接仅承载标题、情绪和封面配置，不包含原始音频；文件分享不受此限制。情绪识别是娱乐性启发式结果，不代表身份、性格或医学判断。
